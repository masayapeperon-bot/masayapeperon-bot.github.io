プライバシーポリシー

「analytics」は、運営者が自分のYouTubeチャンネルの分析にだけ使う個人用のツールです。

取得する情報

YouTube Data API と YouTube Analytics API を通じて、運営者自身のチャンネルの統計情報（再生回数、視聴維持率、流入元など）を読み取ります。書き込みや変更は行いません。

情報の使い方

取得した情報は、運営者のチャンネル運営の分析にだけ使います。

第三者への提供

取得した情報を第三者に提供・販売することはありません。

保存

情報は運営者の端末にだけ保存します。

アクセスの取り消し

Googleアカウントの「サードパーティのアクセス」から、いつでもこのツールのアクセスを取り消せます。
